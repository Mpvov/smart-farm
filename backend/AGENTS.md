# Backend — Luật cho Agent

- **Phạm vi:** API, CSDL, Audit Log, phân quyền và báo cáo HTTT (hiện chưa chốt tech stack, CSDL và mô hình 1 hay nhiều chủ nông trại).
- **Input / Output:** Input từ broker/gateway và request theo `contracts/api.md`; Output là dữ liệu theo contract và bản ghi Audit Log.
- **File được sửa:** Chỉ sửa các file bên trong `backend/`. Không tự chọn CSDL hay framework khi chưa có quyết định trong `docs/decisions/`.
