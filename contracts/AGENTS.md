# Contracts — Luật cho Agent

- **Phạm vi:** Định nghĩa format gói tin UART, topic/payload MQTT, API schema, dữ liệu mẫu và test kiểm chứng.
- **Input / Output:** Input là yêu cầu giao tiếp giữa các phân hệ; Output là đặc tả Markdown, file mẫu trong `samples/` và kết quả chạy `test_contracts.py`.
- **File được sửa:** `contracts/uart.md`, `contracts/mqtt.md`, `contracts/api.md`, `contracts/samples/`, `contracts/test_contracts.py` (chỉ sửa khi cả nhóm đã duyệt và phải sửa đồng bộ contract + mẫu + test trong cùng một commit).
